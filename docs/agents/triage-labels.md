# Triage 标签

各工程 skill 以五个标准 triage 角色交流。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库 tracker 中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

当某个 skill 提到某个角色（例如「应用 AFK-ready 的 triage 标签」），使用上表中对应的标签字符串。

若你的实际词汇不同，直接修改「本仓库 tracker 中的标签」一列。
